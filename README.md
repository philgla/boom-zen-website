# boom-zen-website

Static website for the mobile game **Boom Zen**, served via GitHub Pages (branch `main`) at https://boom-zen.com.

- `index.html` – start page
- `privacy-policy.html` – privacy policy (linked from the app and the Play Console)
- `impressum.html` – legal notice (Impressum, § 5 DDG)
- `CNAME` – custom domain
